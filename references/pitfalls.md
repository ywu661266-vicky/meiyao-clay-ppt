# 为什么分享出去就"退化"（2026-10-22 复盘 · 结论当晚已修正）

> **先纠正一个我自己的误判。**
> 我一开始以为"用户满意的那套 = `clay_text.py` 分件合成做的"，所以把同事的失败归因为"跌进了烘字逃生路"。
> 把用户指出的正品 `课件/专家技能连接器_10页.pptx` 拆开之后，事实是：
> **满意版也是"整页一张图、字烘在图里"做的，10 页全是 1920×1080 单图、没有文字框、没有备注。**
> 分件合成那套根本不是她的成品路径。**是我的 skill 写偏了。**

---

## 一、两版到底差在哪（可量化的 5 条）

| 项 | 满意版 `专家技能连接器_10页` | 同事版 `我的第一部AI视频大片_派派风` |
|---|---|---|
| 页数 | 10 | 17 |
| 单页图片尺寸 | **1920×1080（16:9）** | **1536×1024（3:2）** |
| 放进页面后的占位 | 0,0 起，铺满 13.33×7.5 = **100%** | 宽 11.25、左移 1.04 → **84%，左右各一条白边** |
| 每页信息密度 | 横幅标题 + 副标题 + **4 个色块面板** + 底部结论条 | 标题 + **3 个白胶囊**，大面积空 |
| 配色 | 深紫底 + 紫/绿/橙/红四色面板 + 奶油铭牌 | 浅色底 + 白胶囊，四色体系全丢 |
| 文字 | 烘在图里，黏土字，正确 | 烘在图里，但稀、小 |

**结论：不是"烘字 vs 贴字"的差别，是"尺寸、满版、密度、色系"四条全丢了。**

## 二、这四条为什么会被丢（逃生口在哪）

### 逃生口 1 · skill 正文自己写了"想省事也可以…"

旧 `SKILL.md` 第一性原理那段末尾有一句：
> （想省事也可以让模型顺带烘一个 ≤8 字的黏土标题，见 prompts.md A/B 两路。）

"想省事"三个字，就是明写的逃生门。**规则里只要出现并列选项，下游就会挑简单那套。**

### 逃生口 2 · `prompts.md` 里两套做法并存

封面/目录/总结写"烘进图"，内容页写"留白 + 脚本贴字"。
同一个文件里两套方法并列 → Agent 混着用 → 出来既不是 A 也不是 B。

### 逃生口 3 · 尺寸没有任何硬约束

旧文档只写 `size:"1024x576"`，但没写"出完必须量、不是 16:9 就废"。
同事那套直接混进 3:2，**没有任何一步会拦住它**。

### 逃生口 4 · 没有验收关卡

旧流程交付前只有一句"用 present_files 交付"。
17 页 0 备注、16 页比例错，照样能发出去。

### 逃生口 5 · 我记错了"满意版"是哪一份（这条最要命）

我拿 `好Skill变己用..._v5.pptx` 当"她满意的版本"做基准，那其实是她早就否掉的旧套。
**基准错 → 改的方向也错。** 以后再谈"满意版"，只认她指定的文件，且先拆开量尺寸/占位/密度再下结论。

## 三、已经怎么改的

1. **第一性原理整段重写**：唯一路径 = "一页一张 `1920×1080` 整图，字全部烘进去"，四条硬规格（尺寸/满版/密度/配色）写进表格。
   `clay_text.py` 降级为"只改一两个字时用的补丁工具"，**明确不是主路**。
2. **删掉所有"也可以/想省事"的措辞**，新增铁律 8：*本 skill 只写一条路；要改就替换，不许并列。*
3. **Phase 2/3 改成整页出图**，prompt 必须含四段（画布 / 结构 / 中文原样写进 prompt / 黏土材质句），尺寸锁 `1920×1080`。
4. **新增 `scripts/audit_deck.py`**：交付前必跑，查 16:9 / 满版 / 图片比例=页面比例 / 图宽≥1600 / 版式撞车。
   实测：满意版 **10/10 全过**；同事版 **51 条问题**。
5. **新增 `references/pitfalls.md`（本文）**，把上面五条逃生口钉在这。

## 四、一句话给接收方

> 跑这个 skill，第一个要确认的数不是"字好不好看"，是**每页图是不是 1920×1080、有没有铺满**。
> 只要混进 3:2，后面怎么调都救不回来——投影上就是两条白边。

## 五、逃生口 6（2026-10-22 深夜补，最隐蔽的一个）：画风没锚，每张图都是抽签

尺寸修好后用户仍判"丑/不像"：满意版生动、新跑的呆、人物造型全跑偏。
**根因不是人物锁不锁死**（人物本来就该"谁用就是谁的形象"），是**画风没有任何锚**——
旧流程让每套课件用文字**现生成**角色锚点，满意版的"生动画风"从未被注入新图，等于每套、每页、每个人都在重新抽签。

**修法（已落进 SKILL.md 铁律 4＋9）**：把满意版整套 10 页存进 `assets/style-templates/`，
**强制每张图图生图**：`image1`＝满意版对应页（画风锚），`image2`＝角色锚点（形象锚），prompt 首行加【画风锚定段】。
**纯文字生图一律禁止。** 画风因此稳定可复现，人物仍可换——skill 从"能跑"变成"能稳定出品"。
