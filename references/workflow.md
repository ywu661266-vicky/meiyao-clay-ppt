# 工作流详解（三步确认法）

核心目的：**用最少的出图额度，换用户最满意的结果。** 每次出图前先想清楚"用户要看到什么才能判断对错"。

---

## Phase 0 · 收集素材

一次问清，不要挤牙膏：

1. **内容**：主题 + 每页要讲什么。
   - 有文件就先读文件（`.md` / `.docx` / `.pptx` / `.html`），从里面提取真实内容，不编造。
   - 用户只给关键词时，先列出拟定的页目录（如：封面 / 目录 / 6 个场景 / 总结），**让用户确认页数和顺序**，再动图。
2. **人物**：让他用一句话说清形象，例如"短发、发箍、一个小啾啾、戴眼镜、穿裙子"。
3. **配色**：默认深蓝；一句"要换配色吗"即可，别展开长篇选项。

---

## Phase 1 · 角色锚点（1 张）

- 生成 1 张 `1024x1024`，只做**人物半身**，中性灰底。
- **当场给用户看**，并逐条列出"我核对的特征"（发型/发饰/眼镜/服装），让他一眼确认。
- 不合格 → 按反馈改特征重出 1 张；**永远单张迭代，不批量。**

**话术模板：**
> 这版人物特征对不对？我核对：短发 ✅ 发箍 ✅ 眼镜 ✅ 裙子 ✅。对的话我出封面，不对你说哪要改，我重出。

---

## Phase 2 · 封面（1 张）

- 生成 1 张 `1024x576`，**把主标题以黏土立体字烘进图**（整页效果最直观）。
- **构图自检**：标题要有厚度、有投影、和画面其他黏土件同一材质；如果看着像"贴上去的扁平字"，直接重出，不要给用户看。
- 给用户看时明确说：**"这一张代表整页效果：人物 + 文字 + 场景。"**
- 用户确认 OK → 进入批量；不 OK → 改，仍单张迭代。

**为什么封面要带字：** 用户判断"对不对"靠的是**完整一页的观感**，光给人物看不出效果；带字带场景，一次就能定调。而**字是不是黏土捏的**，恰恰是整套图成败的分水岭。

---

## Phase 3 · 批量内页

页数结构（按需裁剪）：

| 页型 | 数量 | 出图内容 |
|------|------|----------|
| 封面 | 1 | 人物 + 场景 + **黏土立体字主标题** |
| 目录 | 1 | 编号卡/文件夹 + **黏土立体字标题与卡片标签** |
| 内容页 | N | 每页一个知识点 + 左侧铭牌上的**黏土立体字标题** |
| 总结 | 1 | 奖杯/对钩 + **黏土立体字标题** |

- 全部 `size: "1024x576"`。
- 每页 prompt 复制同一段人物 + 风格描述；只改主题、标题文字、道具。
- **每一页的文字都烘进图**（黏土立体字），不再写 `No written words`。
- 每页标题 ≤ 8 字，卡片标签 ≤ 5 字，降低中文写错概率。

---

## Phase 4 · 合成 PPTX

1. 写 `slides.json`：每页 `image` 路径 + `notes`；**图里已有黏土标题的页不要再写 `title`**（避免叠出双层字）。
2. 运行：
   ```bash
   python scripts/build_pptx.py --config slides.json --out "主题_黏土风.pptx"
   ```
3. 校验：页数、16:9 尺寸、**没有被脚本叠上去的扁平标题**、右下角无水印冲突。

> `text_mode` 说明：默认 `baked`（图里已有字，脚本只铺图 + 写备注）；
> 只有成段正文需要可编辑时才用 `overlay`。

---

## Phase 5 · 交付

- `present_files` 交付 `.pptx` + 封面/角色预览图。
- 附一句：页数 / 主题 / 配色 / **标题为画面原生黏土字**（如需改动可再出图或改字）。

---

## 常见翻车与对策

| 现象 | 原因 | 对策 |
|------|------|------|
| 一整套图全废 | 没先确认人物就批量 | 严格执行 Phase 1 单张确认 |
| 人物每页长得不一样 | prompt 里人物描述被改写/省略 | 逐字复制同一段人物描述 |
| **明明是黏土风却很"假"** | **文字是脚本叠的扁平字** | **标题/标签一律烘进图，写成黏土立体字（见 `prompts.md` 第 0 节）** |
| 字和图"不在一个世界" | 只写了"有标题"，没写黏土材质句 | 必须带 `sculpted from thick 3D polymer-clay letters ... not flat printed text` |
| 同一页出现两层标题 | 图里烘了字，脚本又叠了一遍 | `slides.json` 里该页**不写 `title`**（默认 `baked`） |
| 中文出现错字/乱码 | 一次要的字太多 | 单页文字 ≤ 3 处，标题 ≤ 8 字，标签 ≤ 5 字；追加 `correctly formed, no garbled characters` |
| 用户觉得"看不到效果" | 只给了无字人物图 | 封面一定带中文黏土标题 + 场景 |
| 文字压在水印上 | 版式没避开右下角 | 文字统一放左/上，右下留空 |
| 页数不对/顺序乱 | 没先确认目录 | Phase 0 先定页目录再出图 |
