## 复读它时最容易看出、也最该学的三件事

1. **每页只有一个主场景，且它是标题的具象比喻**
   工具箱 / 流程线 / 工作台 vs 手册 / VS 对比 / 三个物件 / 工作流管线 / 门 / 卡片网格 /
   漏斗 / 文件夹 / 分层柜 / 地图 / 实验室 / 齿轮 + 清单。
   **不是"一个车间里堆满道具"。**

2. **至少三分之一是"文字/清单为主 + 一个小道具 + 人物"**
   p16 五个把 / p19 安全四问 / p23 七维度 / p30 六条需求 / p31 命令清单 / p34 问题→改法表。
   别每页都硬造大场景 —— 用户原话：「有时候不用很多元素，而是文字内容」。

3. **清单条目是浮在背景上的厚实黏土胶囊**（p10 七条 / p16 五条）
   整列同色、条间留缝露背景、徽章独立色、右端齐平。**不要嵌进道具板面。**
   规格与做法见 `references/style-library.md` 三·十六。
